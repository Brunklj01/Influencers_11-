# Influencers – Media Presentation

Website-apresentação (trabalho de media) sobre influenciadores, em **inglês e português** (botão PT/EN no topo).

## O que tem
- Pontos 1 a 5: o que é, história, uso hoje, vantagens e desvantagens, jovens e media
- Exemplos de influenciadores (com fotos) e Top 8 mais seguidos
- Dois jogos: "Mais ou menos" (modo difícil) e "Facto ou mito?"

## Como publicar no GitHub Pages
1. Cria um repositório novo no GitHub.
2. Carrega todos os ficheiros desta pasta (`index.html`, `README.md`, `.nojekyll`).
3. Vai a **Settings → Pages**, em *Branch* escolhe `main` e a pasta `/ (root)`, e guarda.
4. Ao fim de um minuto o site fica em `https://O-TEU-UTILIZADOR.github.io/NOME-DO-REPOSITORIO/`.

## Notas
- Está tudo num só ficheiro (`index.html`), incluindo as fotos. Só as fontes vêm do Google Fonts.
- Os números de seguidores são estimativas arredondadas e mudam todos os dias.
- Os avatares desenhados são ilustrações, não fotos reais.
